SolidityDivide is an advanced real-time data processing platform featuring auto-scaling for multi-chain networks and a modular optimizer.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityDivide.git`
2. `cd SolidityDivide`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
